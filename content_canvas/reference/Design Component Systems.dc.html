Surfaces & buttons

the generator · ladder · reserved arcs

Two families, one base shape at 20px radius. A surface is fill only — it holds a term. A button carries a solid base edge it spends when pressed. Colour is generated from a hue angle, not listed, so the set never runs out.

1 · Telling them apart

A surface is flat; a button stands on a solid edge. Depth is the only difference — radius is 20px for both and carries no meaning.

6 · Where the edge colour comes from

Each button's base edge is its own hue at a darker lightness — never a grey, never a shadow.

7 · The ten rules

  1. Depth is the family signal. A surface is flat; a button stands on a solid edge. Radius 20 for both.
  2. Pressing spends the depth. The face travels down by exactly the edge height and lands level with the page.
  3. The edge is flat and derived. A solid offset in the face's own hue — never blurred, gradient, or a lit top.
  4. A surface has no stroke. The stroke appears in one state — highlighted — inset so nothing reflows.
  5. Both fit their content. A shape is never stretched to fill a column.
  6. A variant is a hue angle. Lightness and chroma are fixed, so a ninth colour is generated, never invented.
  7. Two arcs are reserved. 15–40° means wrong, 130–170° means correct.
  8. Hues on one board sit 25° apart. Any closer and two terms stop being tellable apart. Four anchors max.
  9. A term keeps its angle module-wide. If Integers is 250° on board 3, it is 250° on board 17.
  10. Geometry is frozen across states. Only fill, stroke and label colour change.

The slider system

five types · three states · any hue

Markers divide the bar rather than sit on it, the counter is tethered to the thumb, and the track carries the accent's own tint so the whole control reads as one object. Drag any of them.

1 · Anatomy

Five parts — a type is only which parts are switched on. Track 16px, thumb 40px, notch 2px, the hit target 44px whatever the thumb looks like.

4 · Any hue on the ladder

The same control, generated in each of the eight angles — the track tint, fill and notches all derive from one number.

5 · The ten rules

  1. A slider invents nothing. The track is a surface, the thumb is a button with the same base edge, every colour from the hue angle.
  2. The value is shown once. As labels, or as a counter — never both.
  3. Markers cut through the bar. A 2px notch at every interior stop, never a dot resting on the track.
  4. The track wears the accent. A tint of the same hue as the fill, never a neutral grey.
  5. The counter is tethered. It fits its digits and never reserves width it is not using.
  6. Geometry is shared. Track 16px, thumb 40px, notch 2px, in every type, state and hue.
  7. The value is always reachable. The counter shows it, the labels name it, or the driven object makes it obvious.
  8. Discrete means notches. Above 12 stops drop them and use a counter instead.
  9. Highlighted is a surface state. A plate in the stronger tint; the slider itself never changes.
  10. Disabled keeps its geometry. Achromatic fill, no travel, never hidden.

two types · three states · any hue

The value always leads — it is the number being taught, and the two buttons exist to change it. Press anything.

4 · The nine rules

  1. A counter invents nothing. Two buttons and one surface, all from the shape system.
  2. The value always leads. Larger, a step darker and lifted; it leads by hierarchy, never volume.
  3. One hue family, no grey. A button's face is one step lighter than what it sits on.
  4. The value is a surface. Read, not pressed — so it carries no base edge, only a soft lift.
  5. Glyphs are bars, not icons. 4px rounded bars, readable at classroom distance.
  6. A limit disables one button. Never the whole counter.
  7. The value never resizes. Sized for the largest value in range, tabular figures.
  8. Highlighted is a surface state. The shell becomes a plate in the stronger tint.
  9. Disabled keeps the value legible. Glyphs may dim; the number may not.
